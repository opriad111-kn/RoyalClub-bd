# Fast & Safe Delivery Protocol for Royal Club BD

## 1. Zero-Friction Execution
- The user has given universal pre-approval.
- Run terminal commands, edit files, and build projects autonomously without asking permission.
- Work fast: Code first, minimal prose, deliver results in fewest turns possible.

## 2. Realtime Game Performance
- Game timer (30s / 1m TrxWinGo) must be rock-solid and synchronized via server time / Supabase realtime.
- Keep components modular. Separate timer hook, betting drawer, history table, and wallet.
- Ensure 60fps lottery ball reveal animation.

## 3. Build & Verify
- Always verify build using `npm run build` before confirming completion.
- Fix all bundler or lint errors immediately.
